# lekton docs

Plain Markdown, one topic per page. Written to be read by a person or by an agent working for one.

| Page | Read it when |
|---|---|
| [Template format](template-format.md) | You want to define a kind as data, or read one someone else defined |
| [API reference](reference.md) | You need the exact name, arguments, and result of a function |
| [Using lekton from an agent](agents.md) | You are wiring lekton into a model's tool calls or structured output |

Runnable code is in [`examples/`](../examples/). Every example is run by the test suite, so what you read there works.

An index for agents is in [`llms.txt`](../llms.txt) at the root of the repo.
